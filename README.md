# DIO Trilha Básica

Este repositório contém um projeto Java básico desenvolvido como parte da trilha de estudos da DIO (Digital Innovation One).

## Objetivo

O projeto serve como ponto de partida para aprender conceitos fundamentais de Java, incluindo:

- configuração de um projeto Java no VS Code
- compilação de classes Java
- execução de um programa simples
- estrutura básica de um projeto

Pré-requisitos
Antes de executar o projeto, certifique-se de ter instalado:

Java JDK 8 ou superior
VS Code (opcional, mas recomendado)
Extensão Java para VS Code (opcional)
Como executar
Abra um terminal na raiz do projeto e execute:

bash
cd Conta-Banco
javac src/ContaTerminal.java -d bin
java -cp bin ContaTerminal

Hello, World!
